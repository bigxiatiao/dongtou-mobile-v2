## 共享实现

- `src/design-tokens.css` 定义语义颜色、间距、字体和圆角，原样式变量映射到新规范；运行时不再加载旧 `v2/visual-system.css`。
- `src/design-system.css` 统一所有页面的表面、导航、字段、详情、状态、弹层及固定区域。正文 16px、模块 12px、字段组 8px、表单项 16px；普通卡片 12px、无阴影。
- `src/theme.js` 通过 Ant Design 官方 Token 配置主色、按钮、输入、Tabs、Segmented 和弹层。Segmented 使用官方语义类，不依赖其内部 CSS 类名。
- 功能图标仍由显式导入的 `AppIcon` 渲染。描边 1.25px，通过角色尺寸和独立操作热区适配；辅助操作补充了语义图标与名称。
- 中/小按钮通过真实占位中的透明边框分开可视高度和 44px 热区；通知行和分段控件保留足够的实际点击面积。
- 必填标记改为标题后的红色 `*`，保留真实必填规则；非必填标签去掉“选填”字样。
- 转移、部门资料和基层资料校验提供持续文字反馈。可见 Select 同步原生字段的错误状态与 ARIA 关联。
- 修复照片控件嵌套、单位“未完成”误用成功色、窄屏流程条/照片越界，以及 React `noValidate` 属性映射。

## Figma 素材

24 份本地切图位于 `public/assets/figma-home/`，来源图层记录在同目录 `manifest.json`：海湾背景、平台标志、行动背景、预警图片、通知插画、任务卡背景与插画、地图底图、快捷入口背景/图片图标、空状态插画和红绿地图标记。

界面引用本地文件，不依赖临时 Figma 下载地址。图片填充的裁切和缩放由样式保留；业务文字、动态数字、地图点位与操作仍可交互。红色单点切图自带数字 1，因此仅用于单对象点位；绿色切图叠加真实数字，聚合点继续显示业务计数。现场凭证继续来自现有数据或用户选择，不用 Figma 示例人物照片替换实际凭证。

## 验证结果

- 320 / 360 / 375 / 390 / 430px：检查两角色、四部门及列表、详情、办理、批量、资料表单、弹层等状态。初轮 39 个状态的 195 组组合发现的安置模板问题均已修复并复查；之后补查新增编辑、错误状态、批量与弹层。
- 已检查组合未发现页面横向溢出、低于 12px 的可见文字、未命名的纯图标按钮或损坏图片。24 份切图均非空，浏览器请求全部返回 200。
- 实际交互验证包含任务跳转、逐层展开、地图点位与任务/采集切换、搜索和返回、通知、安置点查询、表单校验、选择器、语音弹层、批量选择，以及照片选择后预览。
- `/` 与 `/v2/` 两个本地入口均可加载新规范。
- `npm test`：11 项 React 渲染/控件桥接检查及 5 组原有业务回归脚本通过；包括 68 个原始字段与 12 类表单的字段审计。
- `npm run build`、`git diff --check`、`antd lint src --format json` 通过。构建仍有既有 Ant Design `use client` 指令和大分块提示。
- 最后浏览器检查无 Vite 错误覆盖层，捕获的运行时错误与 `console.error` 为空；之后的 Select 错误状态同步补充了 React 集成回归检查。

## 设计差异与验证边界

预览环境没有 PingFang SC，实际回退到 Noto Sans SC；字形和自然行高与部分设计稿有所差异。为满足 44px 操作热区，通知行、分段控件及相关头部组合比设计稿中的紧凑样例略高。小字号白字按钮采用深蓝，部分数字和状态文字使用加深的语义色；统计保留项目实时数据。

已完成本地浏览器与构建验证，未执行真实后端提交、正式发布、实体设备和多浏览器兼容测试，也未逐项提交每一种可选表单组合。保留的安置登记/转点模板仍沿用原有演示反馈。
